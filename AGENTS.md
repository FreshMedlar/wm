# Python Environment Rule

Always use the Python interpreter and virtual environment located at:
`/home/medlar/Projects/.venv/bin/python`

When running Python commands, tests, or scripts via the terminal, invoke them directly or activate the environment:
- Explicit interpreter: `/home/medlar/Projects/.venv/bin/python <script>.py`
- Or activate beforehand: `source /home/medlar/Projects/.venv/bin/activate`
